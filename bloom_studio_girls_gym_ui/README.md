# Bloom Studio — Women's Fitness UI

A responsive women's gym and wellness dashboard built with **HTML5, CSS3, JavaScript, and Bootstrap 5.3**.

## Run it
1. Extract the project ZIP.
2. Open `index.html` in a modern browser.
3. Internet access is needed for the Bootstrap CDN, Bootstrap Icons, and Google Fonts. The page's custom layout and interactions are in the local files.

## Included UI and interactions
- Responsive desktop sidebar and mobile slide-out navigation
- Overview dashboard, movement stats, hydration tracker, and weekly goal progress
- Class cards for yoga, Zumba, strength training, and Pilates
- Working category filters
- Class booking modal with class/date/time selection
- Demo bookings added to the upcoming schedule and removable booking rows
- Workout category shortcuts
- Workout logging that updates active minutes, class count, and weekly goal
- Toast notifications and scroll-reveal / floating animations
- Reduced-motion accessibility support

## Project files
- `index.html` — page structure and Bootstrap components
- `styles.css` — theme, responsive layout, illustrations, and animations
- `script.js` — interactions and demo state

## Production notes
This is a front-end prototype. Booking, profile, hydration, and progress changes live only in the current page session. For a production gym platform, connect authentication, a database/API, server-side booking validation, membership billing, trainer schedules, and privacy/security controls.
